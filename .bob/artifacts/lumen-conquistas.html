O que mudou

  • 15 → 6. Curado pra "poucas, mas memoráveis" — cada uma representa um marco real, não um contador. "Leu 100 / 500 / 1000 páginas" como 3 conquistas separadas não existe mais; vai pra LumenStatistic no Perfil.
  • Sem cor, sem preenchimento. O selo é só contorno — mesma régua dos ícones funcionais, não um sistema visual à parte.
  • Bloqueada = opacidade baixa, não cadeado. Cadeado é linguagem de jogo. Opacidade baixa é só "isso ainda não aconteceu" — tom mais calmo, consistente com o resto do sistema.
  • Lista com data, não grade. Cada conquista é uma linha com nome + quando aconteceu — não uma prateleira de troféus pra admirar.
