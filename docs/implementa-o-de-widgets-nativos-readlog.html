Configuração iOS obrigatória (Xcode)

A Widget Extension não pode ser criada via CLI — é necessário o Xcode.
1
Abrir ios/Runner.xcworkspace. File → New → Target → Widget Extension. Nome: ReadlogWidgets.
2
Substituir o conteúdo gerado pelo arquivo ios/ReadlogWidgets/ReadlogWidgets.swift.
3
Em Runner e ReadlogWidgets: Signing & Capabilities → + App Groups → group.com.readlog.readlog.
4
Adicionar target no ios/Podfile e rodar pod install.
5
Ver docs/widgets_setup.md para detalhes completos.
