ReadLog — Design System

Referência oficial do layout, tokens visuais, componentes e padrões de tela.
Todo novo código de UI deve seguir este documento.  darklight

1 · Identidade Visual

O ReadLog usa a metáfora de "ficha de biblioteca": papel envelhecido, carimbos de tinta, réguas de sumário e lombadas de livro. A linguagem visual é analógica, silenciosa e literária — sem gradientes, sombras excessivas ou animações decorativas.

Princípio central: cada tela deve parecer uma página de caderno de leitura, não um aplicativo de redes sociais. Cor deve ser usada com parcimônia; o vermelho-carimbo (stamp) é reservado para ações primárias e conquistas.

6 · Padrões por Tela

Home (/home)

Modo: dark · Background: ink · AppBar: dark

Estrutura: ListView com padding fromLTRB(20,16,20,24).

Bloco principal: _StreakRow (carimbo + 2 stat tiles) → metas diárias (se houver) → título "Lendo agora" → lista de ReadLogCatalogCard → botão "Iniciar leitura".

Loading: CircularProgressIndicator(color: brass) centralizado.

Biblioteca (/library)

Modo: light · Background: paper · AppBar: light + ícone add

Estrutura: _StatusFilterBar (background paperAlt, h=46px) + ListView.separated.

Separador: SizedBox(height: 2). Cada item é um ReadLogCatalogCard.

Estado vazio: ícone library_books_outlined 48px + texto mono cinza.

Sessão de Leitura (/session)

Modo: dinâmico — light quando sem sessão ativa, dark durante sessão.

Estado inativo (paper): formulário com DropdownButtonFormField, TextFormField, _GoalPicker (chips), e FilledButton "Iniciar".

Estado ativo (ink): título do livro em Fraunces 20px itálico brassLight, cronômetro IBM Plex Mono 52px, tag "PAUSADO" (brass), barra de progresso do objetivo, botões Pausar/Encerrar.

Sheet de encerramento: BottomSheet com resumo da sessão (ReadLogLeaderRow), campo de página final e notas.

Conquistas (/achievements)

Modo: light · Background: paperAlt

Estrutura: barra de progresso geral (5px, stamp) + 2 grades 3 colunas: "Conquistadas" e "Bloqueadas".

Cada slot: ReadLogStamp 64px + nome mono 9px. Desbloqueado: stamp, rotação -6°. Bloqueado: charcoal 25% alpha, rotação 0°.

Painel (/dashboard)

Modo: light · Background: paper · AppBar: light + ícone share

Estrutura: ListView com padding fromLTRB(20,16,20,32). Seções separadas por _SectionLabel + SizedBox(height:28).

Seções: Hoje (grid 2×2) → Metas → Esta semana → Este mês → Este ano → Calendário de leitura → Atividade (heatmap) → Destaques.

_SectionLabel: Fraunces + linha pontilhada (_DottedLinePainter) até a borda direita.

12 · Regras Adicionais de Qualidade

  • Usar sempre ReadLogColors.* e ReadLogType.* — nunca hardcodar cor ou estilo de texto.
  • O tema ReadLogTheme.light() / dark() é aplicado em main.dart. Telas devem usar Scaffold.backgroundColor diretamente para controle fino (algumas telas são dark em modo light do sistema).
  • Nunca usar Icons.circle ou emojis como marcadores visuais — usar o carimbo (ReadLogStamp) ou badges.
  • RefreshIndicator sempre com color: ReadLogColors.brass.
  • Loading sempre com CircularProgressIndicator(color: ReadLogColors.brass).
  • Estados vazios: ícone outlined ~48px em charcoal 30% alpha + texto mono 12–13px 50% alpha.
  • Divisores: Divider(indent: 16, endIndent: 16), cor paperDeep.
  • Sombras: somente no ReadLogCatalogCard. Outros containers não usam elevação.
  • Animações: somente transições funcionais (chips de objetivo: 180ms). Sem efeitos decorativos.
